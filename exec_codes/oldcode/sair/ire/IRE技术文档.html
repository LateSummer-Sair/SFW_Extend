IRE · Script Language

IRE 脚本语言

一门对 Java 魔改的脚本语言。表达式与语法直接透传 Java 运行时，无需手动编译，转译后由系统自动动态编译执行。兼容 ir 文件，拥有完整的类型系统与控制流能力。

01 · 简介

IRE 是对 SFW 框架的扩充，为 ir 这种纯配置脚本补上了真正的语言能力。它的设计核心是「转译为 Java 源码 → 动态编译 → 当前运行时反射执行」。

优先级、注释、转义、异常处理全部沿用 Java 规则。你在 IRE 里写的表达式，最终就是合法的 Java 表达式。

能力说明
文件扩展名.ire
执行命令ire/run [path] [args...]
入口函数fc main(String args)
兼容性可直接 import 并调用 .ir 文件

02 · 快速开始

新建文件 Hello.ire，写一个入口函数：

Hello.ire
group Hello {
    fc main(String args) {
        SairCons.println(FCM.split_Color, "Hello, IRE!");
        return 0;
    }
}

在 SFW 中执行：

shell
ire/run C:\path\to\Hello.ire a b c

入口参数 a b c 会被拼接成单个字符串 "a b c" 传给 main(String args)。

03 · 文件与 group

一个 .ire 文件只能有一个 group，它会被转译成一个 Java 类（包名固定为 sair.ire.script），类名即 group 名。

MyIre.ire
import {
    java:sair.sys.SairCons;
    java:sair.FCM;
}

group MyIre {
    Int counter = 0;

    fc main(String args) {
        SairCons.println(FCM.split_Color, args);
    }
}

group 内只允许出现 fc 函数和字段声明。

05 · 变量与字段

◆局部变量

ire
String name = "Sair";
Int age = 18;
Double pi = 3.14159;
var anything = "可以接收任何类型";

◆字段

group 内直接声明，转译为 public static 字段。

ire
group Store {
    Int total = 0;
    String title = "未命名";

    fc main(String args) {
        total = 100;
        title = "新标题";
    }
}

06 · 函数 fc

所有函数用 fc 修饰，统一编译为 public static 方法。

ire
// 无显式返回类型：默认返回 Object，无 return 时返回 null
fc sayHello(String str) {
    SairCons.println(FCM.split_Color, str);
}

// 显式返回类型：Int
fc add(Int a, Int b) {
    return a + b;
}

// 无 return 时统一返回 null
fc Int zero() {
}

无 return 时统一返回 null（基础类型已转译为封装类型，不再返回 0/0L/0.0/false/空字符）。

07 · import 导入

import { } 支持三种导入：Java 类、.ire 文件、.ir 文件，以及目录一级扫描。

ire
import {
    // Java 类导入
    java:com.sair.test.*;
    java:com.sair.test.p.Tools;

    // 绝对路径
    C:\Sair\MyLib.ire
    C:\Sair\MyLib2.ir

    // 相对路径
    Sair\MyLib.ire
    ..\..\MyLib2.ir

    // 目录：扫描一级目录下全部（不含子文件夹）
    ..\..\..
}

路径规则：绝对路径、相对路径、.. 表示上一级目录。

★ 同父目录下无需 import

与当前文件在同一目录下的 .ire 和 .ir 文件会自动扫描可用，无需显式 import。

08 · jar 导入

jar { } 用于导入第三方 jar，用法与路径规则和 import 一致。

ire
jar {
    C:\Sair\libs\gson.jar
    ..\libs\jsoup.jar

    // 目录：扫描一级目录下全部 jar
    ..\deps
}

默认已动态导入 SFW.jar、bootlib 与 modlib 中的全部 jar，可直接使用其中任意静态 public 方法。

09 · 调用 ire / ir

◆调用 ire 代码

ire
String args = "hello";
MyLib.func1(args);          // 调用其他 group 的静态函数

◆调用 ir 代码

ire
MyLib2.LabelName_1;   // 跳转执行 ir 中的指定标签块
MyLib2.LabelName_2;
MyLib2;               // 无标签时按 ir 默认主流程顺序执行

ir 调用均为无参数、无返回值调用。

10 · 控制流

◆if / else

ire
if (x > 10) {
    return "大";
} else if (x > 5) {
    return "中";
} else {
    return "小";
}

◆switch / case

ire
switch (n) {
    case 1:
        SairCons.println(FCM.split_Color, "one");
        break;
    case 2:
        SairCons.println(FCM.split_Color, "two");
        break;
    default:
        SairCons.println(FCM.split_Color, "other");
}

◆for / while / do-while

ire
for (Int i = 0; i < 10; i = i + 1) {
    SairCons.println(FCM.split_Color, i);
}

while (x > 0) {
    x = x - 1;
}

do {
    x = x + 1;
} while (x < 10);

◆try / catch / finally

ire
try {
    risky();
} catch (Exception e) {
    SairCons.println(FCM.split_Color, e.getMessage());
} finally {
    cleanup();
}

11 · 表达式与运算

表达式整体透传 Java，支持完整运算能力。

ire
Int a = (1 + 2) * 3;          // 数学运算
Int b = a % 4;                // 取模
Int c = a << 2;               // 位移
Int d = a & 0xFF;             // 位运算
Bool ok = a > 5 && b < 3;    // 逻辑
String s = ok ? "yes" : "no"; // 三目
a += 1; a++;                  // 自增与赋值

12 · 类型转换

使用 IRE 类型名做强转，转译时自动替换为 Java 类型。

ire
Double x = 3.14;
Int y = (Int) x;             // → (Integer) x

var obj = "hello";
String s = (String) obj;     // → (String) obj

13 · 数组

数组类型支持字段、局部变量、参数与返回类型，也支持多维。

ire
group Arr {
    Int[] nums = new Int[3];
    String[][] matrix;

    fc Int[] makeArr(Int n) {
        Int[] a = new Int[n];
        for (Int i = 0; i < n; i = i + 1) {
            a[i] = i * 2;
        }
        return a;
    }

    fc main(String args) {
        Int[] r = makeArr(3);
        return r[2];
    }
}

数组类型的函数无 return 时默认返回 null。

14 · 泛型与 Java 类型

声明位置支持任意 Java 类名、限定名与泛型参数（含嵌套）。

ire
import {
    java:java.util.List;
    java:java.util.Map;
    java:java.util.ArrayList;
    java:java.util.HashMap;
}

group Store {
    java.util.List<String> items;
    Map<String, List<Integer>> map;

    fc java.util.List<String> getList() {
        return new ArrayList<String>();
    }

    fc main(String args) {
        List<String> l = new ArrayList<String>();
        l.add("x");
        Map<String, Integer> m = new HashMap<String, Integer>();
        return l.size();
    }
}

基础类型已统一转译为封装类型，可直接用 Int 作泛型实参：List<Int> → List<Integer>、Map<String, Int> → Map<String, Integer>。

15 · Java 互操作

可直接调用任意 Java 静态 public 方法、创建对象、使用 Java 类库。

ire
import {
    java:java.util.ArrayList;
    java:java.util.List;
}

group Demo {
    fc main(String args) {
        // 静态方法
        String s = String.valueOf(123);

        // 创建对象
        List<String> list = new ArrayList<String>();
        list.add("a");
        list.add("b");

        // 直接使用 SFW 组件
        SairCons.println(FCM.split_Color, list.size());
    }
}

16 · 完整示例

综合示例：两个文件，MyIre2.ire 在 MyIre.ire 的上级目录。

MyIre2.ire
import {
    java:sair.sys.SairCons;
    java:sair.FCM;
}

group MyIre2 {
    fc sayHello(String str) {
        SairCons.println(FCM.split_Color, str);
    }

    fc Int doubleIt(Int x) {
        return x * 2;
    }
}
MyIre.ire
import {
    ../MyIre2.ire
}

group MyIre {
    fc main(String args) {
        MyIre2.sayHello("hello world!!!");
        Int result = MyIre2.doubleIt(21);
        return result;   // 42
    }
}

执行 ire/run C:\path\MyIre.ire，最终在 SFW 中打印 hello world!!!。
