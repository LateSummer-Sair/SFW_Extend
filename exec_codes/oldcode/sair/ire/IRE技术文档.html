IRE · Script Language

IRE 脚本语言

一门建立在 Java 之上的语法拓展层。完全兼容 Java 所有关键字，表达式与语法原样透传 Java 运行时；在此之上叠加 group / fc / var 推断 / 批量修饰符 / 继承糖等特色语法。转译后由系统自动动态编译执行。

01 · 简介

IRE 是对 SFW 框架的扩充，为 ir 这种纯配置脚本补上了真正的语言能力。它的设计核心是「转译为 Java 源码 → 动态编译 → 当前运行时反射执行」。

IRE 不是一门新语言，而是 Java 的语法拓展层：所有 Java 关键字、语句、表达式、注解、泛型、lambda 全部原样透传；ire 只额外提供少量糖（group / fc / var / import{} / jar{} / 类型别名）。

能力说明
文件扩展名.ire
执行命令ire/run [path] [args...]
入口函数fc main(String args)（非 static 实例方法）
兼容性可直接 import 并调用 .ir 文件
Java 兼容class / interface / enum / 泛型 / 注解 / lambda 全部透传

02 · 快速开始

新建文件 Hello.ire，写一个入口函数：

Hello.ire
group Hello {
    fc main(String args) {
        SairCons.println(FCM.split_Color, "Hello, IRE!");
        return 0;
    }
}

在 SFW 中执行：

shell
ire/run C:\path\to\Hello.ire a b c

入口参数 a b c 会被拼接成单个字符串 "a b c" 传给 main(String args)。fc main 会转译为非 static 的实例方法 public Object main(String args)，运行时先实例化再调用。

03 · 定位与设计

IRE 的定位是「把 Java 变成动态的、可控的、可拓展的、针对当前运行时的语言」。它不是重新实现一套类型系统，而是给 Java 蒙一层薄薄的糖衣。

糖含义
group X { ... }转译为 public class X { ... }（唯一 public class）
fc f(...) { ... }转译为方法（默认 public static，支持前置修饰符）
var x = expr转译期类型推断，产物是原汁原味的 Java 类型
[修饰符] : { ... }批量修饰符作用域
class A+B / class A:B+ = extends，: = implements
Int/Bool/Char/LLong类型别名，转译为 Integer/Boolean/Character/BigInteger

其余一切（所有 Java 关键字、语句、表达式、注解、lambda、嵌套类）逐字符原样透传。

04 · 文件与 group

一个 .ire 文件只能有一个 group，它转译为唯一的 public class（包名固定为 sair.ire.script），类名即 group 名。除此之外，文件里可以存在其它非 public 的 class / interface / enum。

MyIre.ire
import {
    java:sair.sys.SairCons;
    java:sair.FCM;
}

group MyIre {
    Int counter = 0;

    fc main(String args) {
        SairCons.println(FCM.split_Color, args);
    }
}

class Helper {          // 非 public 类，原样透传
    Int x = 1;
}

interface Callback { }  // 接口，原样透传

group 内可以出现字段、fc 方法、批量修饰符作用域，以及任意 Java 类成员（嵌套类、static 块等）。

05 · 继承与实现

类声明支持两种语法糖，同时原 Java 关键字依然支持：

ire 写法转译为
class A+B { }class A extends B { }
class A:B { }class A implements B { }
class A+B:C { }class A extends B implements C { }
class A extends B { }原样透传（原关键字）
ire
group Store:java.io.Serializable {   // group 也支持继承/实现糖
    // → public class Store implements java.io.Serializable
}

class Cache+java.util.HashMap {      // class 支持 extends 糖
    // → class Cache extends java.util.HashMap
}

注意：泛型 <...> 内部的 + / : 不会被替换。

★ 关于多继承（class A+B+C+D）

Java 本身不支持类多继承（class A extends B extends C 非法）。当前 IRE 的 + 仅表示单继承（extends），: 表示实现（implements）；class A+B+C+D 这类多继承尚不支持，规划中的落地思路如下：

方案转译形式说明
接口 mixinclass A implements B, C, D（B/C/D 转 interface + default 方法）方法多继承最干净；字段需转 getter/setter
组合 + 委托class A { B b; C c; D d; } + 委托方法实现简单，但非真继承
成员展平把 B/C/D 的字段与方法复制进 A语义最强，但需源码可见
继承链 + 多接口class A extends B implements C, D字段单继承、方法多继承

06 · 类型别名

IRE 类型转译为 Java说明
BoolBoolean布尔
IntInteger整数
LongLong长整型（恒等）
DoubleDouble双精度浮点（恒等）
CharCharacter字符
StringString字符串（恒等）
LLongjava.math.BigInteger超长整型
var（推断）见下一节 var 推断

类型别名按词边界替换，字符串/注释内不替换。基础类型统一转译为封装类型，可直接作泛型实参（如 List<Int> → List<Integer>）。

07 · var 类型推断

var 在转译期就推断出真实类型，产物是原汁原味的 Java 类型，而不是 Object。

写法推断结果
var x = 1int x = 1
var s = "hi"String s = "hi"
var b = trueboolean b = true
var d = 1.5double d = 1.5
var list = new ArrayList<Int>()ArrayList<Integer> list = ...
var arr = new int[5]int[] arr = ...
var x = (String) yString x = ...
var x = foo()foo 的返回类型（本 group 与跨 group，含 fc 推断返回类型）
var x = 1 + 2.5double x = ...（数值提升）
var x = cond ? 1 : 2int x = ...（公共类型）

无法静态推断时（null、lambda、未知类的字段/方法）回退 Object。

◆for-each 元素推断

ire
var list = new ArrayList<Int>();
for (var x : list) { ... }        // x → Integer

var m = new HashMap<String, Int>();
for (var e : m.entrySet()) { ... } // e → Map.Entry<String, Integer>
for (var k : m.keySet()) { ... }   // k → String
for (var v : m.values()) { ... }   // v → Integer

08 · 变量与字段

◆局部变量

ire
String name = "Sair";
Int age = 18;
var anything = "自动推断为 String";

◆字段

group 内的字段默认是实例字段（与 Java 语义一致）；需要静态字段时显式声明 static。

ire
group Store {
    static Int total = 0;     // 静态字段
    String title = "未命名";  // 实例字段（默认）

    fc reset() {              // fc 不默认 public/static，是包私有实例方法（无 return → Object）
        total = 100;          // ✓ 实例方法可访问静态字段
        title = "新标题";      // ✓ 实例方法也可访问实例字段
    }

    static fc Int getTotal() { // 显式 static，仍是包私有
        return total;          // ✓ 静态方法只能访问静态字段
        // return title;       // ✗ 静态方法不能访问实例字段
    }
}

注意：fc 不默认 public 也不默认 static（与 Java 一致）；要 public/static 需显式修饰符。静态方法内只能访问 static 字段。

09 · 批量修饰符作用域

用 [修饰符] : { ... } 把修饰符批量应用到块内每个字段声明与 fc 方法。

ire
private static : {
    int i = 0;
    var a = null;
}
// → private static int i = 0;
//   private static Object a = null;

static : {
    Object o = null;
}
// → static Object o = null;

private : {
    fc foo() { ... }
    fc bar() { ... }
}
// → private static Object foo() { ... }
//   private static Object bar() { ... }

语法是 修饰符 + 冒号 + 花括号（有冒号），与 Java 的 static { }（无冒号静态初始化块）不冲突。

10 · 函数 fc

所有函数用 fc 声明，语法为 [修饰符] fc [返回类型] 函数名(参数) { ... }（修饰符在 fc 之前）。fc 强制返回（与 void 冲突）；无显式返回类型时从函数体推断返回类型；不默认 public 也不默认 static，与 Java 完全一致。

ire
// 无显式返回类型：从函数体推断
fc getNumber() {                // return 1 → int getNumber()
    return 1;
}

fc sayHello(String str) {       // 无 return → Object sayHello()，补 return null
    SairCons.println(FCM.split_Color, str);
}

// 前置修饰符（与 Java 一致，缺省即包私有 + 非 static）
private fc helper() { ... }         // → private Object helper()
protected fc Int calc() { ... }     // → protected Integer calc()
final fc Int getX() { return 1; }   // → final Integer getX()
static fc Int count() { ... }       // → static Integer count()
public static fc Int total() { ... }// → public static Integer total()

// 显式返回类型
fc Int add(Int a, Int b) {
    return a + b;
}

fc 强制返回，与 void 冲突（fc void foo() 会报错）；无显式返回类型时：写了 return 就推断返回值类型（可与 var 联动），没写 return 就补 return null 并推断为 Object。

◆main 入口

fc main(String args) 是运行时入口：转译为实例方法，区别于 Java 的 public static void main(String[])。运行时先实例化，再通过 getDeclaredMethod + setAccessible 反射调用（不受可见性限制）。

ire
group Test {
    fc main(String args) {
        return args;
    }
}
// → public class Test {
//     String main(String args) { return args; }   // 返回类型被推断为 String
//   }

11 · import 导入

import { } 支持三种导入：Java 类、.ire 文件、.ir 文件，以及目录一级扫描。

ire
import {
    // Java 类导入
    java:com.sair.test.*;
    java:com.sair.test.p.Tools;

    // 绝对路径
    C:\Sair\MyLib.ire
    C:\Sair\MyLib2.ir

    // 相对路径
    Sair\MyLib.ire
    ..\..\MyLib2.ir

    // 目录：扫描一级目录下全部（不含子文件夹）
    ..\..\..
}

路径规则：绝对路径、相对路径、.. 表示上一级目录。

★ 同父目录下无需 import

与当前文件在同一目录下的 .ire 和 .ir 文件会自动扫描可用，无需显式 import。

12 · jar 导入

jar { } 用于导入第三方 jar，用法与路径规则和 import 一致。

ire
jar {
    C:\Sair\libs\gson.jar
    ..\libs\jsoup.jar

    // 目录：扫描一级目录下全部 jar
    ..\deps
}

默认已动态导入 SFW.jar、bootlib 与 modlib 中的全部 jar，可直接使用其中任意静态 public 方法。

13 · 调用 ire / ir

◆调用 ire 代码

ire
String args = "hello";
MyLib.func1(args);          // 调用其他 group 的静态函数
// 注意：func1 需声明为 public static fc（跨 group 需 public + static）

◆调用 ir 代码

ire
MyLib2.LabelName_1;   // 跳转执行 ir 中的指定标签块
MyLib2.LabelName_2;
MyLib2;               // 无标签时按 ir 默认主流程顺序执行

ir 调用均为无参数、无返回值调用。

14 · 控制流

控制流语句全部透传 Java，支持 if/else、switch/case、for、while、do-while、try/catch/finally、synchronized、assert、标签、try-with-resources 等。

◆if / else

ire
if (x > 10) {
    return "大";
} else if (x > 5) {
    return "中";
} else {
    return "小";
}

◆switch / case

ire
switch (n) {
    case 1:
        SairCons.println(FCM.split_Color, "one");
        break;
    case 2:
        SairCons.println(FCM.split_Color, "two");
        break;
    default:
        SairCons.println(FCM.split_Color, "other");
}

◆for / while / do-while

ire
for (Int i = 0; i < 10; i = i + 1) {
    SairCons.println(FCM.split_Color, i);
}
for (var x : list) { ... }   // 增强 for，元素类型自动推断

while (x > 0) {
    x = x - 1;
}

do {
    x = x + 1;
} while (x < 10);

◆try / catch / finally

ire
try {
    risky();
} catch (Exception e) {
    SairCons.println(FCM.split_Color, e.getMessage());
} finally {
    cleanup();
}

15 · 表达式与运算

表达式整体透传 Java，支持完整运算能力（含多字符运算符、方法引用、lambda 等）。

ire
Int a = (1 + 2) * 3;          // 数学运算
Int b = a % 4;                // 取模
Int c = a << 2;               // 位移
Int d = a & 0xFF;             // 位运算
Bool ok = a > 5 && b < 3;    // 逻辑
String s = ok ? "yes" : "no"; // 三目
a += 1; a++;                  // 自增与赋值
Int x = (Int) 3.14;           // 强转（(Int) → (Integer)）
Runnable r = () -> { };       // lambda 原样透传

16 · Java 互操作

可直接调用任意 Java 静态 public 方法、创建对象、使用 Java 类库。

ire
import {
    java:java.util.ArrayList;
    java:java.util.List;
}

group Demo {
    fc main(String args) {
        // 静态方法
        String s = String.valueOf(123);

        // 创建对象
        List<String> list = new ArrayList<String>();
        list.add("a");
        list.add("b");

        // 直接使用 SFW 组件
        SairCons.println(FCM.split_Color, list.size());
    }
}

17 · 运行时特性

特性说明
热更新自动重载被 ire/run 执行过的 .ire 文件（含 import）会被监控；文件变更后自动用最近一次参数重新执行。ire/monreload [on|off] 切换
源码哈希缓存脚本内容未变化时跳过转译与编译，直接复用上次字节码
编译失败转储编译失败时把生成的 Java 源码转储到 data/sair.ire.IRE/debug/ 便于排查
监控列表ire/monlist 列出被监控的文件及其状态
卸载已编译类ire/rmclass [className] 清理 cpjavafile/newobject 的编译缓存

18 · 完整示例

综合示例：两个文件，MyIre2.ire 在 MyIre.ire 的上级目录。

MyIre2.ire
import {
    java:sair.sys.SairCons;
    java:sair.FCM;
}

group MyIre2 {
    public static fc sayHello(String str) {   // 跨 group 调用需 public + static
        SairCons.println(FCM.split_Color, str);
    }

    public static fc Int doubleIt(Int x) {    // 跨 group 调用需 public + static
        return x * 2;
    }
}
MyIre.ire
import {
    ../MyIre2.ire
}

group MyIre {
    private static Int count = 0;

    private fc Int increment() {
        count = count + 1;
        return count;
    }

    fc main(String args) {
        MyIre2.sayHello("hello world!!!");
        var result = MyIre2.doubleIt(21);   // result → Integer
        return result;   // 42
    }
}

执行 ire/run C:\path\MyIre.ire，最终在 SFW 中打印 hello world!!!。
