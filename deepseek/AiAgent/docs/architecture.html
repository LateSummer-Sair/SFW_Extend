系统架构

AiAgent 采用「路由与命令实现分离 + Function Calling 统一执行」的分层架构。 从命令入口 → 上下文注入 → 多轮工具调用 → 多智能体协作 → 结果流式输出，形成完整闭环。

Multi-Agent

多智能体协作

两层协作机制：AgentBus 递归通信（运行时互唤）+ AgentOrchestrator 任务编排（显式分解）。

AgentBus 注册表main / vision / passage 三个 Agent
call_agent / ask_agent 工具
main 主模型主管全局上下文与资源调度
唤起 vision
vision 视觉模型分析图像，用 vision 工具
唤起 passage
passage 段落模型概括折叠消息，可反向 ask_agent main
递归返回结果MAX_DEPTH=6 防死循环
AgentBus：把「唤起另一个 Agent」做成 Function Calling 工具
💡
三个协作 Agent 各有专属工具集：main 用全量/execq 工具，vision 用 vision/web/search/searchglobal，passage 用 searchglobal/searchnote/vision。每个子 Agent 的工具集都会额外注入 call_agent / ask_agent，使它能反向唤起其他 Agent，形成双向递归协作。
ai/orchestrate [模式] [任务]显式多智能体编排入口
选择编排模式pipeline / fanout / expert
PIPELINE 流水线
任务分解为有序子步骤规划器拆分，按顺序串行执行
FANOUT 扇出扇入
拆独立子任务并行执行各自完成后聚合结果
EXPERT_POOL 专家池路由器按任务类型选 coder/researcher/writer/general
聚合最终结果所有子步骤结果汇总返回
AgentOrchestrator：任务分解 + 多 Agent 协作编排
