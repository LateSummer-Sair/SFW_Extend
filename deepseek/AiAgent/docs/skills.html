技能系统

AI 执行轨迹自动蒸馏为可复用技能，分层技能库（general/execq/task/persona）。 支持内置技能、三方技能（含代码段）、agentskills.io 技能包、路径权重路由。

Overview

Builtin

内置技能库

SystemSkillLib（scope=general，24+ 条）+ NapCatSkillLib（scope=execq，40+ 条）。

🧰

SystemSkillLib

通用工具使用说明、记忆系统架构、时效性信息查询、Java 动态注入、三方技能库管理、agentskills.io 技能包使用说明、callskill 使用说明、系统闹钟（alarm）等 24+ 条系统技能。

🐱

NapCatSkillLib

NapCat API 技能，含群管操作流程、身份权限层级、@提及系统、消息转工具流程、文件路径构造规则、跨群操作、转发/转告等 40+ 条。

💡
内置技能通过 addBuiltinSkill() 写入，使用 contentHash 去重，同 hash 合并跳过，避免重复注入。
Third Party

三方技能（含代码段执行）

data/skills/ 目录单文件 .md 技能，WatchService 文件监听。

放入 .md 文件data/skills/*.md，front matter 声明 name/description
ThirdPartySkillStore 扫描parseMarkdown 提取元数据 + 四种代码段
环境依赖检测java/js 原生 · nodejs/python 需命令行
动态注册工具airun 签名 → tp_技能名，Function Calling 直接调用
SkillCodeRunner 执行airun 入口（强制返回值）
三方技能代码段执行链路
⚠️
代码段权限受 /setthirdpartycode 控制：on=放权（所有通道含 QQ）；off=仅 execs/本地可用。
Package

agentskills.io 技能包

AgentSkillStore 负责技能包存储 + 监听 + zip 自动解压。

📦

技能包加载

将符合 agentskills.io 标准的技能包（含 SKILL.md）放入 data/skillpackages/ 目录即自动加载；zip 技能包放入后自动解压导入并删除原 zip。

🔍

环境依赖审查

加载时探测 skillhub/jq/curl 等依赖，缺失时用 SFW 红字输出提示用户自行安装。渐进式披露：索引只放元数据，正文按需读取。
