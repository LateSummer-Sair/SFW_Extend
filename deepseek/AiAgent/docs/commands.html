命令参考

所有命令以 ai/ 为前缀，通过 SFW 控制台输入。共 58 个用户命令 + 74 个 FC 工具（另有动态注册的 tp_* 工具）。 v3.9 特性：热路径提速（getPlainText 单次提取、KV 前缀缓存命中、群资料/偏好/日志短 TTL 缓存）、token 去重、群成员写库去重治理、有界 LRU 缓存、FC 请求体序列化缓存、遥测落库异步化。

Core

核心命令

配置、对话、记忆、安全、系统命令。

命令参数分类说明
ai/setkey[API Key]配置设置 DeepSeek API 密钥，AES-GCM 加密存储（兼容旧 ECB），持久化到 config.properties
ai/seturl[URL]配置设置 API 地址，默认 https://api.deepseek.com
ai/setmodel[模型名]配置设置模型，默认 auto。auto 下本地 execs 走 deepseek-v4-pro、QQ execq 走 deepseek-v4-flash（智能路由）
ai/setthirdpartycodeon|off配置三方技能代码段权限：on=放权（含 QQ）；off=仅 execs/本地
ai/setprompt[提示词]配置设置系统提示词（持久化），AI 也可通过 editprompt 工具修改
ai/showprompt—配置查看当前系统提示词全文
ai/config—配置查看配置摘要（含思考模式/温度/top_p）+ 对话统计 + 记忆条数 + 数据目录
ai/status—配置查看运行时状态：OneBot、Redis、FileServer、线程池、最近 Harness/工具轨迹、技能与记忆计数
ai/setconfig[key] [value]配置统一配置开关：思考模式/温度/top_p/最大输出/惩罚项/strict/botname 等，持久化 config.properties
ai/execs[任务]对话唯一 Agent 入口（合并 chat/exec/execs/execfc），原生 Function Calling 免确认全能模式
ai/chat / exec / execfc[消息]对话execs 的别名，统一走 Function Calling 链路
ai/orchestrate[pipeline|fanout|expert] [任务]对话多智能体编排：流水线 / 扇出扇入 / 专家池三种模式，任务分解为子步骤并聚合结果
ai/harnesseval—对话输出最近 Harness 执行轨迹评测报告（成功率 / 平均工具调用 / 耗时）
ai/criticon—对话开启 Harness 验证闭环审查（每次最终回复增加一次独立审查，opt-in）
ai/criticoff—对话关闭 Harness 验证闭环审查（默认）
ai/reset—对话清空对话上下文 + Agent 记忆链
ai/stop—对话立即中断当前流式输出
ai/mood—情绪查询 AI 当前心情 + 开心值 + 连续失败/夸赞次数
ai/memories—记忆列出所有持久化记忆
ai/forget[ID]记忆按 ID 删除指定记忆
ai/forgetall—记忆清空所有持久化记忆
ai/exportdata[lib] [path]备份导出库为 JSON（lib=memory/note/impression/sticker，path 缺省存数据目录）
ai/importdata[lib] [path]备份从 JSON 导入库（清空覆盖原库）
ai/autoclearon—系统启用自动清屏，每 3 分钟 /clear 防日志 OOM
ai/autoclearoff—系统停止自动清屏
ai/qqlogon / qqlogoff—系统开启 / 关闭 QQ 消息控制台输出

Deployment

部署指南

编译、打包、部署三步完成。

1

编译

使用 SFW 内置 JDK (8x64) 编译全部 93 个源文件。classpath 需包含 SFW.jar、gson、zxing、jsoup。

javac -encoding UTF-8 -cp "SFW.jar;gson.jar;zxing-core.jar;zxing-javase.jar;jsoup.jar" -d out sair/aiagent/**/*.java
2

打包

使用 jar 命令打包，MANIFEST.MF 必须包含 ACT: sair.aiagent.AiAgentActivity;

jar cfm AiAgent.jar META-INF/MANIFEST.MF -C out .
3

部署

将 AiAgent.jar 复制到 SFW 的 plugins/exection/ 目录，启动 SFW 后即可使用 ai/ 命令。

Copy-Item AiAgent.jar plugins/exection/AiAgent.jar
