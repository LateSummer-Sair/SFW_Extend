更新日志

AiAgent 从 V1.0 本地聊天助手，一路演进到 V3.7 全功能智能代理 —— Function Calling 多轮循环、四层记忆、技能自进化、Harness 多智能体编排、QQ OneBot 机器人、多模态识图。

V3.x

V3.0 系列 · 智能化与编排

识图模型上线、技能自进化、Harness 编排、多智能体通信、日志治理。

  • V3.7
    日志输出治理 + 全通道调用追踪
    日志不再写文件，统一输出到 SFW 控制台；execs/execq/QQexecs 全通道记录 Agent 探索了什么、调用了什么工具、任务抛给了哪个 Agent
  • V3.6
    触发词多词化 + 多智能体通信
    消息触发词支持多个（; 分隔，settrigger 工具动态修改）；AgentBus 多智能体通信（call_agent/ask_agent）；折叠消息解析修复；按需识图 + 段落摘要
  • V3.5
    多模态识图增强 + 群印象 + 好感度排行
    引用图片 file(md5) 兜底、图片 3M + File API；群印象系统；好感度排行（本群 Top10 / 全局仅主人）；AgentSkillStore 技能包重构（zip 自动解压）
  • V3.4
    消息 Mark 防重 + 系统闹钟 + 多主人
    markmessage 消息处理防重机制；系统闹钟 AI Alarm（语义解析 once/daily/weekly）；多主人支持；数据导出导入（exportdata/importdata）
  • V3.3
    Harness 多智能体编排 + 可观测性
    AgentOrchestrator 三种编排模式（pipeline/fanout/expert）；HarnessTrace 轨迹 SQLite 持久化 + HarnessEval 评测；五级上下文压缩管线；统一多线程治理
  • V3.2
    技能自进化 + 路径路由
    SkillExtractor LLM 轨迹蒸馏 + RouteCache 路径权重缓存；技能 scope 四分类（general/execq/task/persona）
  • V3.1
    表情包系统 + 人格印象系统
    StickerManager 表情包自动收集/发送；ImpressionExtractor 蒸馏五维人格画像，回复时自动注入印象上下文实现个性化交互
  • V3.0
    识图上线 · 移除 OCR
    全面改用 DeepSeek 识图模型（多模态 Vision），彻底移除在线 OCR 依赖
