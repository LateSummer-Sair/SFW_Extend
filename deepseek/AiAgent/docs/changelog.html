更新日志

AiAgent 从 V1.0 本地聊天助手，一路演进到 V3.9 全功能智能代理 —— Function Calling 多轮循环、八库记忆、技能自进化、Harness 多智能体编排、QQ OneBot 机器人、多模态识图、热路径性能治理。

V3.x

V3.0 系列 · 智能化与编排

识图模型上线、技能自进化、Harness 编排、多智能体通信、日志治理。

  • V3.9
    性能深度治理：热路径提速 + token 去重 + KV 前缀命中 + 写放大治理
    QQ 上下文构建每条消息 getPlainText() 只提取一次并贯穿复用（原约 10 次 CQ 码正则剥离）；稳定技能索引前置到 user 消息首部，命中 DeepSeek KV 前缀缓存，动态历史不再破坏前缀稳定；群管理员/群昵称映射/群名/个人昵称映射加 60s 短 TTL 缓存，并移除原本每条群消息都失效缓存的逻辑，让读缓存真正生效；listPreferences / buildJournalContext 加 60s 内存 + Redis 缓存，写入即失效，偏好/日志上下文不再每条消息重复查库拼接；FC 请求体改用共享静态 Gson + 按工具列表对象身份缓存 tools 序列化，构建 execs/execq 工具集结果缓存；AiConfig 触发词缓存；遥测 recordToolTrace / recordTrace 异步提交到共享单线程 TraceWriter 池落库，工具执行与 FC 主链路不再同步等待 SQLite INSERT；语音/视觉结果缓存改为有界 LRU（500/1000），防长期运行无限增长；群成员角色/昵称/成员关系写库去重（内存快照，值未变化跳过 REPLACE），修复群印象 gimp: 缓存被每条消息失效的问题，大幅降低每条群消息的 DB 写放大；QQ 统一记忆库补热路径索引（conversations/group_chat_history），会话裁剪 DELETE 降为每 50 次写入执行一次，消除全表扫描；短消息（去标点 <4 字）不再触发记忆/笔记/纠正/日志检索门控；群回复后总是给当前被回复消息打〖已回复〗标记，修复正常回复（非引用）场景下历史里已回答问题被重复回答的答非所问
  • V3.8
    跨机器媒体发送修复 + 记忆通道修复 + 运行时状态
    图片/语音/表情包本地文件增加 base64 兜底发送（解决 NapCat 在 Linux 无法下载 Windows 本地路径的「下载文件失败: Bad Request」）；sendimage 不再误报成功，失败返回真实错误；remember 工具 execq 通道写入统一记忆库、本地通道写 aiagent.db；新增 filehost 配置命令手动指定文件中转服务对外地址；新增 ai/status 运行时状态与 tool_call_traces 工具调用轻量遥测；AiConfig 加载后增加配置校验日志，非法端口/越界参数回退默认值
  • V3.7
    日志输出治理 + 全通道调用追踪
    日志不再写文件，统一输出到 SFW 控制台；execs/execq/QQexecs 全通道记录 Agent 探索了什么、调用了什么工具、任务抛给了哪个 Agent
  • V3.6
    触发词多词化 + 多智能体通信
    消息触发词支持多个（; 分隔，settrigger 工具动态修改）；AgentBus 多智能体通信（call_agent/ask_agent）；折叠消息解析修复；按需识图 + 段落摘要
  • V3.5
    多模态识图增强 + 群印象 + 好感度排行
    引用图片 file(md5) 兜底、图片 3M + File API；群印象系统；好感度排行（本群 Top10 / 全局仅主人）；AgentSkillStore 技能包重构（zip 自动解压）
  • V3.4
    消息 Mark 防重 + 系统闹钟 + 多主人
    markmessage 消息处理防重机制；系统闹钟 AI Alarm（语义解析 once/daily/weekly）；多主人支持；数据导出导入（exportdata/importdata）
  • V3.3
    Harness 多智能体编排 + 可观测性
    AgentOrchestrator 三种编排模式（pipeline/fanout/expert）；HarnessTrace 轨迹 SQLite 持久化 + HarnessEval 评测；五级上下文压缩管线；统一多线程治理
  • V3.2
    技能自进化 + 路径路由
    SkillExtractor LLM 轨迹蒸馏 + RouteCache 路径权重缓存；技能 scope 四分类（general/execq/task/persona）
  • V3.1
    表情包系统 + 人格印象系统
    StickerManager 表情包自动收集/发送；ImpressionExtractor 蒸馏五维人格画像，回复时自动注入印象上下文实现个性化交互
  • V3.0
    识图上线 · 移除 OCR
    全面改用 DeepSeek 识图模型（多模态 Vision），彻底移除在线 OCR 依赖
