Impression

人格印象系统

ImpressionExtractor 蒸馏每个 QQ 用户的 5 维人格画像，回复时自动注入个性化上下文。

用户消息recordImpressionMessage 记录每条
消息计数message_count >= 10 触发
LLM 蒸馏5 维：友好度/可信度/活跃度/专业性/情绪倾向
写入 ImpressionEntry以 QQ 号为键持久化
回复时注入toPromptContext() 个性化语气
人格印象蒸馏与注入链路
Correction

纠正记录

corrections 表 + 多观点查询，AI 犯错时记录，避免重复犯错。

📌
correct 工具记录纠正信息，支持 topic（归类检索）+ viewpoint（同主题多观点区分），注入上下文时按主题检索。
Lifecycle

记忆生命周期

MemoryLifecycleManager 守护线程（30 分钟间隔）重要性分级清理 + 数量阈值压缩。

守护线程启动30 分钟间隔

是
重要性分级清理低重要性优先压缩
否
跳过等待下轮
数量阈值压缩旧记忆合并摘要
完成exit() 时 stop()

QQ Memory

统一 QQ 记忆

UnifiedQQMemoryManager 统一存储所有 QQ 对话，source_type/source_id 标记区分群聊/私聊。

🗄️

qq_unified_memory.db

单数据库统一存储，FTS5 全文索引，记忆联通（群聊/私聊可跨查）；group_chat_history_fts 支持跨群检索群聊历史（中文 N-gram 兜底）。

🏷️

来源标记

source_type（group/private）+ source_id（群号/QQ号）区分来源，getGroupNicknameMap 获取群昵称映射。

🔎

searchglobal 全局检索

AI 回答「某用户/某群之前聊了什么」时调用 searchglobal 工具，综合群聊历史、对话记录、长期记忆三源检索；涉及隐私的内容由 AI 判断是否透露。
