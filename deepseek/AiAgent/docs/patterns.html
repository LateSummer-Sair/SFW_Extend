设计模式

项目运用 16 种设计模式贯穿架构：单例、门面、策略、观察者、工厂、命令、模板方法、 桥接、状态机、建造者、生产者消费者、守护线程、降级模式、多智能体递归通信、多智能体编排、线程池模式。

Patterns

设计模式清单

1️⃣

单例模式 Singleton

AiConfig / PromptManager / SkillBank / StreamPrinter / RedisClient / FileServer / HarnessConfig 全局唯一实例。

2️⃣

门面模式 Facade

PersistenceManager 统一管理 13+ 张表，MemoryManager 封装记忆 CRUD。

3️⃣

策略模式 Strategy

DeepSeekClient chatStream/chatSync/chatSyncWithTools 三种策略 + model=auto 智能路由（pro/flash）。

4️⃣

观察者模式 Observer

WatchService 文件监听：ThirdPartySkillStore / AgentSkillStore 监听技能目录变化自动重载。

5️⃣

工厂模式 Factory

ToolDispatcher buildAllTools/buildExecqTools/buildExecsTools 三套工具工厂 + tp_ 动态工具注册。

6️⃣

命令模式 Command

ActivityActions.route() 路由 57 个命令到 handle* 方法，命令与执行解耦。

7️⃣

模板方法模式 Template Method

AgentExecutor executeFcLocal/executeFcExecq/executeFcExecs 共享 buildSystemPrompt + FC 循环模板。

8️⃣

桥接模式 Bridge

QQAgentBridge / FunctionCallingBridge 桥接 QQ 通道与 Agent 引擎。

9️⃣

状态机模式 State Machine

EmotionManager / EmotionStateManager 情绪状态机，情绪阈值触发状态迁移。

🔟

建造者模式 Builder

ToolDefinition addString/addOptionalString/addProperty 链式构建 JSON Schema。

1️⃣1️⃣

生产者消费者模式

StreamPrinter LinkedBlockingQueue FIFO 队列，生产者 offer + 消费者逐字打印。

1️⃣2️⃣

守护线程模式 Daemon

AutoDistill（5min）/ MemoryLifecycleManager（30min）/ AutoClear（3min）/ CronScheduler / AlarmScheduler / StickerManager 清理。

1️⃣3️⃣

降级模式 Fallback

FunctionCallingBridge eval 兜底 + Redis 旁路降级 + WebSocket 文件回退本地路径。

1️⃣4️⃣

多智能体递归通信 AgentBus

把「唤起另一个 Agent」做成 call_agent / ask_agent 两个 Function Calling 工具，main/vision/passage 三个 Agent 双向递归协作，MAX_DEPTH=6 防死循环。

1️⃣5️⃣

多智能体编排 Orchestrator

AgentOrchestrator 流水线 / 扇出扇入 / 专家池三种模式，任务分解 + 子代理执行 + 结果聚合。

1️⃣6️⃣

线程池模式 Thread Pool

ThreadManager 统一命名线程池 + OneBot 连接池 + FC 多工具并发 + execPool 可配置背压 + 工具超时。
