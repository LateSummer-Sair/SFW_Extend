类结构详解

93 个 Java 源文件，81 个 public 类型，总计 37,597 行代码，按职责划分为 9 个包。 采用「路由与命令实现分离 + Function Calling 统一执行 + 多智能体递归协作」的架构。

Core

core 核心模块（47 类 + 插件入口）

核心引擎：Agent / Function Calling / 工具分发 / 持久化 / 技能 / 多智能体。入口 AiAgentActivity（sair.aiagent 包）一并列出。

🎬

AiAgentActivity

sair.aiagent

SFW 插件入口。main() 路由命令，初始化全部核心组件 + AutoDistill 自主蒸馏守护线程 + MemoryLifecycleManager + HistoryCompressor + OneBot QQ + AutoClear 守护线程。

🗄️

PersistenceManager

sair.aiagent.core

SQLite 统一持久化核心（aiagent.db，WAL + FTS5）。多表：memories/journal/conversations/stickers/cron_tasks/notes/skills/impressions/corrections/group_impressions/image_remarks/harness_traces/tool_call_traces/alarms。ensureColumn 幂等迁移。

⚙️

AiConfig

sair.aiagent.core

单例配置管理器。API Key AES-GCM 加密存储（兼容旧 ECB）。DeepSeek 高级参数 + Redis。模型解析（唯一规则）：model=auto 才启用自动路由，getExecqModel()/getChatModel()/getAgentModel()/getVisionModel() 各自返回该通道默认模型 deepseek-flash；model=具体模型名 时严格按配置的模型名调用、所有通道一律使用该名称不做替换（业务代码不再硬编码模型名）。若硬指定不支持视觉的模型，识图时给出告警而不擅自替换。加载后校验关键配置并记录回退日志。

📝

PromptManager

sair.aiagent.core

集中式提示词管理器（单例）。Java 内不保留任何提示词正文：systemPrompt.md / execqPrompt.md / agentPrompt.md 三份文件优先从 data/prompts/ 读取（找不到回落到数据目录根），标记行加载时剥离，改文件即热重载，文件缺失就是空提示词、不报警；getSystemPrompt()/getExecqPrompt()/getAgentStaticPrompt() 统一入口，setSystemPrompt()/appendSystemPrompt() 只替换「角色设定」段。

🤖

AgentExecutor

sair.aiagent.core

FC 执行入口。executeFcLocal / executeFcExecq / executeFcExecs / executeOrchestrated 四通道。buildSystemPrompt() 融合上下文，轨迹收集用于技能蒸馏；registerAgents() 注册多智能体（main/passage 跟随通道模型，vision 为视觉兜底且 skipPreprocess 防递归）。

🔄

FunctionCallingBridge

sair.aiagent.core

原生 Function Calling 多轮循环引擎。runWithDispatcher() 驱动 tools/tool_calls 循环（不设轮次与工具调用次数上限，由 Agent 自身判断任务是否完成；仅连续失败 5 次兜底提示 / 10 次终止与显式停止才中断）；图片按需以多模态 content 块随 user 消息直接提交，不再单独调用视觉模型。

🎯

sair.aiagent.core
