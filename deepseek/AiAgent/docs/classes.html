PersistenceManager

SQLite 统一持久化核心。单文件数据库 aiagent.db，WAL 模式，FTS5 全文搜索，替代 5 个独立 JSON 文件。5 张表：memories / memories_fts / journal / conversations / app_state。事务安全，旧数据自动迁移。

集中式提示词管理器（单例）。三段提示词统一入口：systemPrompt（控制台Chat）、execqPrompt（QQ通道）、agentStaticPrompt（Agent执行）。硬编码默认值 + config.properties 追加模式持久化。setSystemPrompt/setExecqPrompt 走追加写入，重启不丢失。

Core (v2.6)

CronScheduler

sair.aiagent.core · 210 行

定时任务调度引擎（基于 ScheduledExecutorService）。支持标准 cron 表达式（6 段式：秒分时日月周），持久化到 PersistenceManager 的 cron_jobs 表。addJob() 注册任务并启动调度线程，removeJob() 取消并清理，listJobs() 查询所有任务状态。AI 通过 <schedule> 标签管理任务生命周期（add/list/delete/enable/disable）。任务触发时注入 AgentExecutor 走完整 ReAct 执行链路。服务重启自动恢复所有 enabled 任务。

Core

AgentExecutor

sair.aiagent.core · 1400 行

ReAct 推理-行动循环引擎。最多 30 轮循环，execq 通道 50 轮。20 种 Agent XML 标签。execq 通道 21 种标签（11 工具 + 10 群管），受白名单门控，工具类标签自动绕过确认。v2.3 新增 executeQq() 多模态重载。v2.5 新增 qqExecsCallback 回调机制，思考过程缓冲后以合并转发卡片发送。v2.6 模型自动路由：execq 使用 getExecqModel()（auto→flash），Agent 使用 getAgentModel()（auto→pro）。

Core (v2.5)

StickerManager

表情包管理器。管理 SQLite stickers 表（通过 PersistenceManager）：collectSticker() 自动收集 QQ 聊天中的图片到表情库（存储文件路径、上下文对话、关键词、时间戳），findMatchingSticker() 根据语境关键词匹配最相关表情包，cleanupOldStickers() 清理过期表情。支持按关键词检索和按时间排序。
