类结构详解

92 个 Java 源文件，80 个 public 类型，总计 31,602 行代码，按职责划分为 9 个包。 采用「路由与命令实现分离 + Function Calling 统一执行 + 多智能体递归协作」的架构。

Core

core 核心模块（46 类 + 插件入口）

核心引擎：Agent / Function Calling / 工具分发 / 持久化 / 技能 / 多智能体。入口 AiAgentActivity（sair.aiagent 包）一并列出。

🎬

AiAgentActivity

sair.aiagent

SFW 插件入口。main() 路由命令，初始化全部核心组件 + AutoDistill 自主蒸馏守护线程 + MemoryLifecycleManager + HistoryCompressor + OneBot QQ + AutoClear 守护线程。

🗄️

PersistenceManager

⚙️

AiConfig

sair.aiagent.core

单例配置管理器。API Key AES-GCM 加密存储（兼容旧 ECB）。DeepSeek 高级参数 + Redis。模型智能路由：getAgentModel()/getExecqModel()/getVisionModel()。

📝

🤖

🔄

FunctionCallingBridge

sair.aiagent.core

原生 Function Calling 多轮循环引擎。runWithDispatcher() 驱动 tools/tool_calls 循环（无轮次上限，连续失败/无进展自动终止，失败 5 次切 eval 兜底）。

🎯

ToolDispatcher

🧭

工具执行上下文。携带通道信息 + QQ 上下文（NapCatApi + QQMessage）+ 主人/好感度标记 + agentBusDepth 递归深度。

🔧
