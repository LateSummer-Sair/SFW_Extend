AiAgent · 智能代理插件

SairFrameWork 框架的 AI 智能代理 — 原生 Function Calling 多轮循环、三层通道权限模型、 技能自进化、四层记忆系统、Harness 多智能体编排、QQ OneBot 机器人（统一记忆 + 群管理）、多模态图片识别。 对接 DeepSeek V4 Vision API，流式逐字输出，SQLite 全局持久化，统一多线程治理。

Overview

核心能力

从「对话」到「自主任务执行」再到「群管理」，一个插件全面接管 SFW 框架。

  • ✓
    原生 Function Calling 多轮循环
    FunctionCallingBridge 驱动 tools/tool_calls 多轮循环（无轮次上限 + 连续失败/无进展自动终止），ToolDispatcher 统一注册与执行工具，模型自主决定聊天或调工具
  • ✓
    三层通道权限模型
    本地 execs（全量工具）→ QQ execq 普通消息（受限工具 + 仅 NapCat 技能）→ QQ execs: 关键字（全工具 + 全技能）。越权立即终止
  • ✓
    技能自进化 + scope 四分类
    SkillBank + SkillExtractor LLM 轨迹蒸馏 + RouteCache 路径权重缓存。scope 分 general/execq/task/persona，按通道按需注入
  • ✓
    三方技能库（含代码段执行）
    单文件 md 支持 java/js/nodejs/python 代码段，airun 入口签名动态注册为 tp_ 工具，直接 Function Calling 调用；agentskills.io 技能包渐进式披露
  • ✓
    四层记忆系统
    memories（持久记忆）/ notes（知识库）/ skills（技能）/ impressions（人格印象）四层架构，FTS5 全文检索 + 重要性加权 + 时间衰减
  • ✓
    QQ OneBot v11 机器人
    反向 WebSocket 接手群聊私聊，统一记忆库区分群聊/私聊，完整群管理（禁言/踢出/拉黑/设管/改群名/退群），跨群操作
  • ✓
    多模态图片识别
    DeepSeek V4 Vision 智能分析，二维码拦截（含码不存），图片注释 MD5 强绑定持久化，引用图片触发 OCR
  • ✓
    人格印象系统
    ImpressionExtractor 蒸馏每个 QQ 用户 5 维人格画像，回复时自动注入印象上下文实现个性化交互
  • ✓
    动态代码注入与执行
    Nashorn JS 即时执行 + JavaCompiler 编译注入，编译→加载→执行→丢弃。execq 通道 evaljs 受限
  • ✓
    联网搜索 + 文件下载 + 天气
    HTTP GET（SSRF 内网黑名单 + DNS Rebinding 检测），必应搜索、文件下载、实时天气（Redis 旁路缓存）
  • ✓
    情绪陪伴 + 好感度六级权限
    情绪状态机（被夸开心/被骂难过/连续失败撒娇暂停），好感度 0~1000 六级权限：100 加好友 / 200 改马甲 / 300 入新群 / 400 挚友关注 / 800 恋人 5% 监听 / 1000 提至 10%，捐赠按 1元=1分
  • ✓
    好感度查询 / 调整 / 复位 / 排行
    queryaffection 查单个/群成员/随机抽取，setaffection 主人调整任意用户（昵称/QQ/群），affectionrank 本群 Top10（全局仅主人），resetaffection 一键复位；群成员关系表 + 内存缓存双层结构，按群号高效排序
  • ✓
    跨群记忆检索
    群聊完整历史 FTS5 全文索引 + 中文 N-gram 兜底，群与群之间共享记忆（如「隔壁群谁喊妈妈」可跨群命中）
  • ✓
    拟人化监听态
    消息并发处理（execPool 3 线程），每个监听群独立进入 8~20 秒监听窗口，AI 判定相关性自动续期，同群 8 次边界暂停，挚友/恋人概率主动关注
  • ✓
    好友申请 / 群邀请 AI 决策
    好友申请与群邀请不再自动处理，进入待处理请求池，AI 通过 pendingrequests/approvefriend/acceptgroupinvite 等工具按好感度决策；捐赠由主人私聊告知，AI 用 recorddonation 工具记录
  • ✓
    Cron 定时 + 自动清屏
    标准 cron 表达式持久化定时任务，重启恢复；AutoClear 守护线程每 3 分钟防日志 OOM
  • ✓
    系统闹钟（AI Alarm）
    alarm 工具创建到点唤醒 AI 的闹钟：语义解析 once/daily/weekly 三种 schedule，上下文快照持久化，到点重建上下文走 Agent 链路执行任务（一次性触发即完成自动移除）；普通用户到点仅提醒、主人走受限链路、execs/本地走全权限
  • ✓
    配置持久化 + AES 加密
    API Key AES-GCM 加密存储（兼容旧 ECB 回退），DeepSeek 高级参数（reasoning/温度/频率惩罚）自动保存
  • ✓
    模型智能路由
    model=auto 时本地 execs 走 deepseek-v4-pro（深度推理）、QQ execq 走 deepseek-v4-flash（轻量快速）
  • ✓
    Harness 多智能体编排
    AgentOrchestrator 三种编排模式：流水线 pipeline / 扇出扇入 fanout / 专家池 expert，任务分解为子步骤并聚合结果（/orchestrate）
  • ✓
    Harness 可观测性
    HarnessTrace 执行轨迹 SQLite 持久化 + HarnessEval 评测报告（成功率/平均工具调用/耗时），FC 循环全程埋点（/harnesseval）
  • ✓
    五级上下文压缩管线
    ContextPipeline L1 token 预算 → L2 截断 → L3 LLM 摘要 → L4 重要性加权 → L5 FTS 检索，动态分配各层上下文预算
  • ✓
    统一多线程治理
    ThreadManager 统一命名线程池 + OneBot 连接池 + FC 多工具并发执行 + execPool 可配置背压 + 工具执行 120s 超时
