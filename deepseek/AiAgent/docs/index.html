AiAgent · 智能代理插件

SairFrameWork 框架的 AI 智能代理 —— 原生 Function Calling 多轮循环、三层通道权限模型、 多智能体协作（AgentBus 递归通信 + AgentOrchestrator 编排）、技能自进化、八库记忆系统、 QQ OneBot 机器人（统一记忆 + 群管理 + 好感度体系）、原生多模态识图。 对接 DeepSeek V4.1 Flash API，流式逐字输出，SQLite 全局持久化，统一多线程治理。

Overview

核心能力

从「对话」到「自主任务执行」再到「群管理」，一个插件全面接管 SFW 框架。

  • ✓
    原生 Function Calling 多轮循环
    FunctionCallingBridge 驱动 tools/tool_calls 多轮循环（无轮次与工具调用次数上限，由 Agent 自身判断任务是否完成，仅连续失败/显式停止才终止），ToolDispatcher 统一注册与执行工具，模型自主决定聊天或调工具
  • ✓
    多智能体协作 · AgentBus
    注册 main / passage / vision 三个 Agent，通过 call_agent / ask_agent 互相唤起、双向递归协作（MAX_DEPTH=6 防死循环）。按模型视觉能力动态启用：Flash 通道下 main 与 passage 自己就能看图（vision Agent 自动不启用）；Pro 通道下由 vision Agent 兜底识图，其执行模型写死 deepseek-flash
  • ✓
    多智能体编排 · AgentOrchestrator
    pipeline（流水线）/ fanout（扇出扇入）/ expert（专家池）三种编排模式，把复杂任务分解为子步骤并聚合结果（ai/orchestrate 命令）
  • ✓
    三层通道权限模型
    本地 execs（全量工具）→ QQ execq 普通消息（受限工具 + 仅 NapCat 技能）→ QQ execs: 关键字（全工具 + 全技能）。越权立即终止
  • ✓
    技能自进化 + scope 四分类
    SkillBank + SkillExtractor LLM 轨迹蒸馏 + RouteCache 路径权重缓存。scope 分 general/execq/task/persona，按通道按需注入
  • ✓
    三方技能库（含代码段执行）
    一个技能一个文件夹（md 文档 + Java 源码），airun 入口签名动态注册为 tp_ 工具，直接 Function Calling 调用；辅助类同目录一起编译；工具名自动规范化为合法字符集；默认权限位 AFFECTION:300（zip 式技能包已移除）
  • ✓
    八库记忆系统
    memories / notes / skills / impressions / conversations / stickers / corrections / group_impressions 八库架构，FTS5 全文检索 + 重要性加权 + 时间衰减
  • ✓
    QQ OneBot v11 机器人
    反向 WebSocket 接手群聊私聊，统一记忆库区分群聊/私聊，完整群管理（禁言/踢出/拉黑/设管/改群名/退群），跨群操作
  • ✓
    原生多模态图片识别
    DeepSeek V4.1 Flash（deepseek-flash）原生支持视觉：图片按需直接作为多模态 content 块随消息提交，不再单独调用视觉模型（彻底移除在线 OCR），图片注释 MD5 强绑定持久化
  • ✓
    戳一戳系统拦截
    戳一戳不再走 AI 思考：系统直接拦截并 @ 戳的人回一个「？」，零 token 消耗、响应即时
  • ✓
    人格印象系统
    ImpressionExtractor 蒸馏每个 QQ 用户 5 维人格画像，回复时自动注入印象上下文实现个性化交互
  • ✓
    动态代码注入与执行
    Nashorn JS 即时执行 + JavaCompiler 编译注入，编译→加载→执行→丢弃。execq 通道 eval/evaljs/sys 受高危代码模式拦截
  • ✓
    联网搜索 + 文件下载 + 天气
    HTTP GET（SSRF 内网黑名单 + DNS Rebinding 检测），必应搜索、文件下载、实时天气（Redis 旁路缓存）
  • ✓
    情绪陪伴 + 好感度六级权限
    情绪状态机（被夸开心/被骂难过/连续失败撒娇暂停），好感度 0~1000 六级权限：100 加好友 / 200 改马甲 / 300 入新群·发文件·发语音 / 400 挚友关注 / 800 恋人 5% 监听 / 1000 提至 10%，捐赠按 1元=1分
  • ✓
    好感度查询 / 调整 / 复位 / 排行
    queryaffection 查单个/群成员/随机抽取，setaffection 主人调整任意用户，affectionrank 本群 Top10（全局仅主人），resetaffection 一键复位；群成员关系表 + 内存缓存双层结构
  • ✓
    跨群记忆检索
    群聊完整历史 FTS5 全文索引 + 中文 N-gram 兜底，群与群之间共享记忆（如「隔壁群谁喊妈妈」可跨群命中）
  • ✓
    折叠消息全交段落 Agent + 标记去重
    折叠消息（不论引用与否）一律由 passage 段落 Agent 分析，结论注入后由主 Agent 自己调用 markmessage 标回原消息并标识「已分析」；下轮按 message_id 精确查 + 内容兜底查，命中即复用，绝不重复分析
  • ✓
    群聊回复 @ 提问者（不引用）
    取消 Bot 主动引用回复（引用错乱根因是引用 ID 与消息归属不匹配），改为系统自动 @ 当前提问者并强化「本次回复对象」标识，减少识别难度
  • ✓
    拟人化监听态
    消息并发处理（execPool 3 线程），每个监听群独立进入 8~20 秒监听窗口，AI 判定相关性自动续期，同群 8 次边界暂停，挚友/恋人概率主动关注
  • ✓
    好友申请 / 群邀请 AI 决策
    好友申请与群邀请不再自动处理，进入待处理请求池，AI 通过 pendingrequests/approvefriend/acceptgroupinvite 等工具按好感度决策；卡片消息（群邀请/好友申请）解析提取内容并注入系统拦截结果告知 AI，不再误答「空消息」；捐赠由主人私聊告知，AI 用 recorddonation 工具记录
  • ✓
    表情包存图多智能体协作
    存图由主 Agent 打包段落（仅好感度>6、排除 Bot 自己、无图不分发）→ 段落 Agent 找图 → 视觉 Agent 识图 → 判断收藏 → collectsticker → markmessage；TTL 被动/主动双通道（保底 15 / 阈值 30 / 上限 60，3 天 TTL）
  • ✓
    Cron 定时 + 自动清屏
    标准 cron 表达式持久化定时任务，重启恢复；AutoClear 守护线程每 3 分钟防日志 OOM
  • ✓
    系统闹钟（AI Alarm）
    alarm 工具创建到点唤醒 AI 的闹钟：语义解析 once/daily/weekly 三种 schedule，上下文快照持久化，到点重建上下文走 Agent 链路执行任务；普通用户到点仅提醒、主人走受限链路、execs/本地走全权限
  • ✓
    配置持久化 + AES 加密 + 校验日志
    API Key AES-GCM 加密存储（兼容旧 ECB 回退），DeepSeek 高级参数（reasoning/温度/频率惩罚）自动保存，加载后校验关键配置并记录回退日志
  • ✓
    模型解析（auto 才路由）
    model=auto 时才启用自动路由，各通道取默认模型 deepseek-flash（V4.1 Flash，原生多模态）；配置里写了具体模型名则严格按该名称调用，所有通道一律照用、不做任何替换
  • ✓
    Harness 可观测性 + 工具遥测
    HarnessTrace 执行轨迹 SQLite 持久化 + HarnessEval 评测报告（成功率/平均工具调用/耗时），ToolCallTrace 记录每次工具调用轻量遥测，ai/status 查看运行时状态与最近轨迹
  • ✓
    统一多线程治理
    ThreadManager 统一命名线程池 + OneBot 连接池 + FC 多工具并发执行 + execPool 可配置背压 + 工具执行 120s 超时
