权限与通道

三层通道权限模型将「本地」与「QQ」隔离，按通道收缩工具集与技能范围。 越权调用立即终止并告知无权限，高危操作需确认门控放行。

Model

三层权限模型

从最高权限到受限，逐层收紧。

① 本地 execs（console）全量工具 buildAllTools + 技能（general/task/persona）· 免确认
② QQ execs:（主人关键字）全量工具 + 全技能（含 NapCat）· 权限提升
③ QQ execq（普通消息）受限工具 buildExecqTools + 仅 NapCat 技能 · 越权立即终止
权限从高到低：本地 execs → QQ execs: → QQ execq

QQ Permissions

QQ 通道权限细节

🛡️

execq 工具集（55 个）

仅保留 NapCat 群管/媒体工具 + web/readfile/readdir/weather/time/remember/correct/note/searchnote/balance + 表情包 + setimageremark + 好友申请/群邀请决策（pendingrequests/approvefriend 等 6 个）+ recorddonation/donationlist/resetdonation 捐赠工具（仅主人）+ queryaffection/setaffection/affectionrank 好感度三工具 + alarm 系统闹钟（普通用户到点提醒、主人 AI 任务）。移除 sys/evaljs/download/schedule/skillextract。

🔐

cmd 权限门禁

execq 的 cmd 仅允许 help（格式：组件名/help 或 /help），其他命令越权立即终止并告知无权限。

⚡

evaljs 彻底禁用

execq 不注册 evaljs。eval 仅限多对象拆分搜索的联网抓取，禁止文件系统操作、进程执行、反射、类加载。

👑

修改型指令仅主人

setname / setsignature 等修改型指令加 isMasterOnly 拒绝，非主人调用立即终止并告知无权。
